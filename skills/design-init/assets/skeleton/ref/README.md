# Reference material

Project-specific inputs and constraints — approved sources, scope boundaries,
provenance. They are **not** design authority: `DESIGN.md` governs the visual
language. Where a reference and the package differ, the package wins; where the
package is silent, a reference shows intent.

**This folder persists after `design-init` runs.** The derivation role is
one-time, but scope docs remain live constraints for every later
design-draft/design-system run, visual sources remain the fallback where the
package is silent, and the folder is the inbox for future approved material.
References are frozen — replace a file and update this table when superseded;
never edit in place.
